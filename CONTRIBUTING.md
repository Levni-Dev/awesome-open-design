# Contributing

This list collects open-source design tools and openly licensed design resources. It is curated by [Levni-Dev](https://github.com/Levni-Dev) under one rule: **no FOMO, only open**.

## What gets in

- **Open.** Code under an OSI licence, or assets under an open licence (CC0, CC BY, OFL, MIT…). "Free for personal use" is not open.
- **Free to use.** No credit card, no paid API key, no waitlist to get started. Optional paid hosting is fine if the open version works on its own.
- **Alive.** Not archived, and maintained (a push in the last year, or a classic that still works).
- **Useful.** It does something real today. Say what, in one line.

Your own project is welcome. So is a project you love that is not yours.

## How to suggest something

The easy way: [open a suggestion](../../issues/new?template=suggest.yml). A maintainer, sometimes with an AI helper, turns good suggestions into a pull request and credits you.

Or open a pull request yourself:

1. Add one line in the right section, in this exact shape:
   `` - [Name](https://link) - What it does, in plain words. `Licence` ``
2. Keep the description under about 110 characters, no hype, no emoji.
3. One project per pull request.
4. Add it to `data/entries.json` too, if you can.

Every entry is checked by hand before it is merged. Links are checked automatically every week.
